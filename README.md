# Quantum Cortex

A research notebook for notes at the edge of quantum physics and neuroscience.

Live site (after GitHub Pages finishes): https://fg5yv6s7gp-ui.github.io/quantum-cortex/

## What works
- Read sample papers
- Search and filter by tag
- Post your own title, authors, abstract, tags, and link
- Delete your own posts

Posts are saved in the browser (`localStorage`). They are not in a shared database yet.
